# Guerrilla de La Niebla (1816)

Proyecto final Informática II. Videojuego 2D en C++ / Qt.
Rocket Raccoon con tropas patriotas en la Guerrilla de La Niebla.

## Abrir el proyecto
1. Qt Creator → Open Project → `GuerrillaLaNiebla.pro`
2. Kit Desktop Qt 6 (o 5)
3. Build & Run

## Controles actuales
A/D o flechas: mover
W / Up: saltar
Espacio: disparar
G: granada
Shift: dash
F: furia
